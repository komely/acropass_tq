# 나의 TQ (My TQ) — 프로토타입 시안

ACROPASS 트러블큐어(트큐) 캠페인용 참여형 마이크로페이지. **광고주 제안 시연용 시안**이며 모든 문구·데이터는 교체 가능합니다.
**모바일 전용 시안**입니다(기준 폭 390px, 최대 430px 고정). PC 전용 레이아웃은 만들지 않았습니다.

## 기능
- 인트로 → 16문항 테스트(진행 바·이전 이동) → 분석 연출 → 앱 5탭 (알기 · 주기 · 돌보기 · 읽기 · 나누기)
  - **알기**: 유형 카드 / 성향 리포트(축별 % 막대, 왜 이런 결과인가, 케어 제안 3개) / **주기 케어 진입 카드** / Lab Note·제품 연결 / **내 유형에 맞는 칼럼 2편** / 엔딩 카피 / 고정 안내 문구
  - **주기** (신규): 내 트러블 주기에 따른 케어. 올라온 날짜를 달력으로 기록하면 현재 단계와 단계별 케어 3개를 보여줌
    - 주기형(R): 안정기 → 준비기 → 예상 구간 → 올라온 뒤 4단계. 기록된 '올라온 시기'가 2번 이상이면 평균 간격으로 다음 예상 구간(참고용)과 D-day를 계산
    - 돌발형(S): 예측하지 않고 평소 대비 / 올라온 직후 2단계 + '갑자기 올라온 날 3단계' 안내
    - 케어 3개 = 타이밍 모듈 1 + 요인(I/E) 모듈 1 + 대응(Q/W) 모듈 1 을 조합 (16유형 × 단계 모두 자동 생성)
    - 단계 탭으로 다른 단계 케어를 미리 볼 수 있음. 날짜만 저장
  - **돌보기**: 캐릭터 '딱이'(가제, 표정 3단계), 데일리 미션 3개(WHY 한 줄), **주기 케어 바로가기**, 7일 챌린지 달력 스탬프, 딱 포인트("혜택 준비 중"만 표시)
  - **읽기** (신규): 전문가 칼럼 8편(시안). 카테고리 필터 4종, 내 유형과 겹치는 칼럼을 '나와 맞아요'로 추천, 상세(필진 프로필·본문·Key Takeaways·관련 탭 연결 버튼), 읽음 표시
  - **나누기**: 9:16(1080×1920) PNG 카드 저장, 링크 복사, Web Share API(미지원 시 링크 복사), 친구 TQ 궁합 카드
- 로그인·개인정보 입력란 없음. 외부 유료 API 없음 (폰트만 jsDelivr의 무료 Pretendard 사용, 실패 시 시스템 폰트)

## 파일 구조 (수정 포인트)
| 파일 | 내용 |
|---|---|
| `data/config.js` | **버튼 링크(올리브영·자사몰, 현재 `#`)**, 포인트 규칙, 챌린지 일수, 화면 고정 문구, 결과 강도 문구, 금칙어 목록 |
| `data/questions.js` | 16문항 (축·가중치·선택지 극) |
| `data/modules.js` | 축별 모듈 8개 (별명·요약·왜 이런 결과인가·케어 제안) — 16유형은 이 조합으로 자동 생성 |
| `data/missions.js` | 미션 풀(요인·대응·타이밍·공통) + 'WHY' 문구 |
| `data/labnotes.js` | Lab Note 카드와 제품 소개 (H: 트러블큐어 / F: 카밍파우더) |
| `data/compat.js` | 궁합 모듈 (축별 일치/보완 8개 + 일치 개수별 타이틀 5종) |
| `data/cycle.js` | 주기 케어: 판정 규칙값(`rules`), 단계 정의·케어 문구, 요인·대응 모듈, 돌발형 SOS |
| `data/columns.js` | 전문가 칼럼 8편, 카테고리, 가상 필진 4명, 추천용 `tags` |
| `js/cycle.js` | 기록 저장·삭제, 에피소드 묶기, 평균 간격·예상 구간·단계 판정, 케어 조합 |
| `css/style.css` | `:root` 변수: **브랜드 컬러, 로고(`--logo-*`), 폰트, 캐릭터 색(`--char-*`)** |
| `js/engine.js` | 판정·문구 조합·미션 선정·궁합·금칙어 점검 |
| `js/character.js` | 캐릭터 SVG 모듈 조합 |
| `js/share.js` | 카드 이미지·공유 |
| `js/store.js`, `js/app.js` | 저장소 / 화면 |

### 로고 교체
`css/style.css` 의 `:root` 에서 `--logo-image: url(...)`, `--logo-img-display: block`, `--logo-text-display: none` 으로 바꾸면 됩니다.

## 판정 로직
- 코드 순서: 타이밍(R/S) · 형태(H/F) · 요인(I/E) · 대응(Q/W). 예: SHIQ
- 축당 4문항, 핵심 문항 1개는 가중치 1.5(합계 4.5) → 동점이 나오지 않음
- 막대 %는 가중 득점 비율. 60% 미만이면 "균형에 가까운 편이에요" 문구
- 16문항 이진 테스트 결과이므로 정확도를 주장하지 않음

## 저장소 (localStorage, 키 `tq.v1`)
`answers`, `result{code,pct,at}`, `startDate`, `daily{날짜:{code,ids,done}}`, `points{total,log}`, `bonusPaid`, `dayOffset`(시연용), **`cycle{logs:['YYYY-MM-DD']}`**(올라온 날짜), **`read{ids:[]}`**(읽은 칼럼).
키는 `tq.v1` 그대로이며, 이전 버전에서 저장된 데이터는 지우지 않고 `cycle`·`read` 필드만 보충합니다.
이름·연락처 등 개인 식별 정보는 저장하지 않습니다. 브라우저·시크릿 모드가 바뀌면 기록은 보이지 않습니다.

## 규칙
- 7일 챌린지: 시작일부터 7일 안에 미션 1개 이상 클리어한 날이 7번이면 완주(연속 불필요). 스탬프는 1개 이상 연한 색, 3개 진한 색
- 포인트: 미션 1개 = 1딱(체크 해제 시 회수), 완주 보너스 +5딱 (`config.js`)
- 캐릭터 표정: **오늘** 미션 달성도 0개 뾰로통 / 1~2개 보통 / 3개 편안. 캐릭터를 없애거나 물리치는 연출 없음
- 표현 기준: 진단·처방·치료·여드름 등 금지, "~한 편이에요" 어조. 하단 고정 문구는 알기 탭 맨 아래에 있음
- 주기 판정: 5일 이내 연달아 기록한 날짜는 한 번의 '올라온 시기'로 묶음 · 마지막 기록 후 7일은 '올라온 뒤' · 예상 구간 7일 전부터 '준비기' · 간격 편차가 14일을 넘으면 구간을 넓게 잡고 안내 (`data/cycle.js` 의 `rules`)
- 예상 구간은 입력한 날짜만으로 계산한 **참고용 추정**이며 화면에도 그렇게 표시함. 의학적 판단이 아님
- 콘솔에서 `[TQ lint]` 로 금칙어·보장 표현을 점검하고, `[TQ selfTest]` 로 16유형 조합을 점검

## 시연 바로가기 (주소 파라미터)
- `?demo=SHIQ` 해당 유형 결과로 진입 (기존 결과를 덮어쓰므로 주소에 직접 넣었을 때만 동작)
- `&tab=know|cycle|care|read|share` 탭 지정, `&done=0~3` 오늘 미션 N개 완료 상태로 시작
- `&cycle=calm|prep|window|after|none` 주기 샘플 기록 넣기(기존 주기 기록을 덮어씀, 시연용)
- `&col=c01` 칼럼 상세 바로 열기, `&cat=habit` 칼럼 카테고리 지정, `&goto=cycleTeaser|colTeaser` 알기 탭의 해당 위치로 스크롤
- `?start=N` N번 문항에서 테스트 시작
- `?ref=SHIQ` 친구 유형 코드가 담긴 공유 링크 (인트로 배너, 궁합 자동 입력)
- 앱 상단 ⚙ 설정: 16유형 전환, 주기 샘플 기록 넣기/지우기, 다음 날로 넘기기(스탬프 시연), 테스트 다시 하기, 기록 삭제

## 검증 현황
- 모바일(390px) 렌더링으로 인트로·테스트·결과·돌보기·나누기 화면 확인, 콘솔 오류 없음, 금칙어 0건, 16유형 조합 누락 0건
- 5탭 개편 후: 주기(R형·S형)·읽기 목록·칼럼 상세·알기 탭 진입 카드·돌보기 바로가기를 모바일로 확인하고, 주기 판정 로직 17개 항목(단계 4종, 돌발형 무예측, 기록 0·1개, 중복·미래·형식 오류, 묶기, 이월, 16유형×단계 48개 케어 조합, 칼럼 무결성)을 점검해 모두 통과
- 실제 기기에서는 확인하지 않았습니다: 이미지 저장 다운로드, Web Share 공유 시트, 클립보드 복사(HTTPS에서만 동작)

## 남은 일 / 주의
- 공유 링크(`?ref=`)는 배포 주소가 정해져야 실제로 쓸 수 있습니다. 아직 배포하지 않았습니다.
- 제품 링크는 `#`이며, 누르면 "링크 준비 중" 안내가 뜹니다.
- Lab Note 근거와 제품 문구는 시안입니다. 집행 전에 근거 자료와 광고 심의·법무 검토가 필요합니다.
- 캐릭터 이름 '딱이'는 가제입니다.
- 공유 카드에는 미션 달성도와 무관하게 '편안' 표정을 고정으로 넣었습니다.
- 전문가 칼럼의 필진 4명(김서연·박도윤·이하은·정민재)과 직함, 본문은 모두 **가상 시안**입니다. 실제 집행 시 전문가 섭외·검수와 근거 자료 연결, 광고 심의 검토가 필요합니다.
- 칼럼은 8편이라 일부 극(I·R·S·W·F)은 맞는 글이 1편뿐입니다. 편수를 늘리면 추천이 더 다양해집니다.
- 주기 예상은 날짜 기록 2번 이상부터 동작하며, 기록이 적을수록 정확도가 낮습니다. 시연에는 ⚙ 설정의 샘플 기록을 사용하세요.
- 하단 탭이 3개에서 5개로 늘어 한 칸이 좁아졌습니다. 실제 기기에서 터치 영역을 한 번 더 확인해 주세요.
